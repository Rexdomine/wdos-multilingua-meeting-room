# Onboarding Hon. Ngunan Addingi as Country Representative, Nigeria (WGMN)
Browser only, about three minutes, on build v67.2 · db 109.

1. Sign in as HQ. HQ Operations → **Accounts** → **Add leader / member**.
2. Fill: First name Ngunan · Last name Addingi · Email beekasinvest@gmail.com ·
   Network WGMN · Country Nigeria · Volunteer role "Country Representative" ·
   Volunteer ID (your CR code for Nigeria, e.g. CR-NG) · tick Volunteer leader.
   Leadership seat: Role = Country Representative, Unit = type "Nigeria" and pick it.
   Leave the temporary password empty (WDOS generates one). Press **Create login**.
3. The login details appear once: copy them and send them to her privately.
   She changes the password under Settings after her first sign-in.
4. On her row press **Photo** and choose `docs/photos/ngunan-addingi.jpg` from this
   package (her picture, 675 × 675). It appears on her dashboard and in the Atlas.
5. Press **View as** on her row: her dashboard must read
   "Welcome, Ngunan!" · Volunteer ID · full name · WGMN · Country Representative,
   Reports To: WODDI HQ, and Direct Reports: every state coordinator seated in Nigeria.

If the email already has a login (the error "already has a WDOS login"), search
for it on Accounts and use Role / seat instead of Add leader.

Note on the current Nigeria line: the Kwara assistant's dashboard showed
"Reports To: Patience Opega, Country Representative, WODDI HQ", meaning a
country_rep seat exists at the HQ unit. Seat Hon. Addingi at Nigeria; if the
Nigeria line should report to her and not to the HQ-level seat, that is
exactly what the Nigeria seat does.
